# Hijri Date and Moon Phase (Arabic) — Joomla 5 Module

A Joomla 5 site module that displays the civil (tabular) Hijri date and an approximate moon phase in Arabic, RTL-ready.

**Developer:** [ArabSkyPedia](https://arabskypedia.com) — موسوعة السماء العربية

## Features

- Civil Hijri date in Arabic (e.g. 14 جمادى الآخرة 1448 هـ)
- Approximate moon phase name in Arabic with moon age and illumination percentage
- Arabic and English language files; RTL layout
- Two display options: show/hide Hijri date, show/hide illumination

## Accuracy disclaimer

The Hijri date is computed with the civil/tabular arithmetic calendar and the moon phase from a mean synodic month. Both are approximations: they may differ by a day from official calendars that apply their own rules (e.g. Umm al-Qura) and from local sighting announcements. This module does not determine crescent visibility.

## Install

1. Download the latest `mod_hijri_moon_ar` zip from [Releases](../../releases).
2. In Joomla administrator: System → Install → Extensions → upload the zip.
3. Go to Content → Site Modules, open "Hijri Date and Moon Phase (Arabic)", set a position, publish.

Requires Joomla 5.x (tested on 5.4) and PHP 8.1+.

# إضافة التاريخ الهجري وطور القمر — جوملا 5

إضافة (موديول) لجوملا 5 تعرض التاريخ الهجري المدني وطور القمر التقريبي باللغة العربية.

## تنبيه الدقة

التاريخ الهجري محسوب بالتقويم الحسابي المدني، وطور القمر بالشهر القمري المتوسط؛ وكلاهما تقريبي وقد يختلف يومًا عن التقاويم الرسمية ذات القواعد الخاصة (مثل أم القرى) وعن إعلانات الرؤية المحلية. الإضافة لا تحدد إمكانية رؤية الهلال.

## التركيب

حمّل أحدث حزمة من صفحة الإصدارات، ثم من لوحة تحكم جوملا: النظام ← تثبيت ← الإضافات، وارفع الحزمة، ثم انشر الموديول في موضع من اختيارك.
